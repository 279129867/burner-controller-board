## 项目简介

本项目对标工业电控 / 燃烧控制 / 硬件电子工程师岗位要求，把温度采集、火焰检测、阀门驱动、4-20mA、RS485、CAN、隔离与 EMC 防护整合为一块完整主控板，重点展示：

- 系统方案与器件选型取舍（含国产替代）
- 模拟采集、隔离输入/输出、通讯、电源隔离的电路设计思路
- 接地分区、强弱电分离、防护器件布局等 PCB/EMC 设计考虑
- 关键链路的电路级与逻辑级仿真验证
- 完整工程文档（规格书、BOM、IO 分配、测试记录、面试话术）

> 本阶段不依赖实物样机：模拟链路用 Python 做直流工作点与一阶 RC 时域仿真，数字/协议/联锁逻辑用脚本验证；LTspice 复现搭法见仿真记录目录。

## 系统架构

```
现场侧（工业现场 24V/强电）
  ├─ 温度传感器（热电偶 K 型 / PT100）──► 信号调理 ─┐
  ├─ 4-20mA 变送器（炉膛温度/压力/氧含量）──► I/V ─┤
  ├─ O₂ / CO 探头（毫伏/毫安级）──────────► 调理 ──┤
  ├─ 火焰检测器（开关/脉冲）──────────────► 隔离调理 ─┼─► MCU(STM32)
  ├─ 干接点/脉冲输入（风压/水位/限位）──────► 隔离输入 ──┤
  ├─ RS485（上位机/PLC）◄──隔离收发──────────────────┤
  ├─ CAN（炉区联调/机组总线）◄──隔离收发─────────────┤
  ├─ 阀门/风门驱动（继电器/光耦）◄──隔离输出──────────┤
  └─ 报警输出 ◄──隔离输出───────────────────────────┘

电源域：
  24VDC ─► 防反接/保险/TVS ─► 非隔离 DC-DC(数字+模拟供电)
                      └─► 隔离 DC-DC ─► 现场侧/通讯侧隔离供电
  数字地 / 模拟地 / 功率地 / 现场地 分区，单点汇接。
```

## 技术指标

| 项目 | 指标 |
|---|---|
| 工作电源 | 24VDC（18~36V 宽压） |
| 主控 | STM32G0/G4 级别（Cortex-M0+/M4F），同级国产可替代 |
| 模拟采集 | 温度 2~4 路；4-20mA 3~4 路；O₂/CO 1~2 路；≥12bit ADC |
| 数字输入 | 火焰 1~2 路；干接点 4~6 路；脉冲 1~2 路（光耦隔离） |
| 数字输出 | 阀门/风门 4~6 路；报警 2 路（光耦隔离） |
| 通讯 | RS485 ×1（Modbus-RTU）；CAN ×1（CAN 2.0B） |
| 隔离 | 现场侧与控制侧 DC-DC 隔离；数字/模拟/功率/现场地分区 |
| EMC 对标 | 浪涌 ±1.5kV、脉冲群 ±1kV、ESD ±8kV 接触（设计预留，待实测） |

- Python 3.10+（开发使用 3.13）

pip install numpy

## 仿真结果摘要

### 4-20mA I/V 链路（电路级仿真）

| 输入电流 | 采样电压 V_s | ADC 输入 V_adc | ADC 码值（12bit） |
|---|---|---|---|
| 4mA | 1.00V | 0.62V | 773 |
| 12mA | 3.00V | 1.87V | 2318 |
| 20mA | 5.00V | 3.11V | 3863 |

- 分压比 `k = 16.5k/(10k+16.5k) ≈ 0.623`，满幅 3.11V，未超 3.3V 量程。
- RC 时间常数 `τ = 1kΩ × 100nF = 100µs`，截止频率 `fc ≈ 1.59kHz`。
- 20mA 阶跃：90% 建立 ≈ 230µs，99% 建立 ≈ 460µs。

### 逻辑仿真（脚本验证通过）

- 4-20mA 码值→电流换算；<3.6mA 判断线，>21mA 判过载。
- Modbus-RTU 组帧与 CRC16 校验 PASS；CAN 帧 ID/DLC/Data 结构正确。
- 燃烧联锁状态机：运行中熄火 / 风压不足 → 切断主燃阀、副阀并报警。

### 电源输入级（电路级仿真）

| 输入 | 后级电压 | 状态 |
|---|---|---|
| 18V | 18.00V | OK |
| 24V | 24.00V | OK |
| 30V | 28.00V（TVS 钳位） | OK |
| 36V | 28.00V（TVS 钳位） | OK |
| -24V | 0.00V | 反接阻断 |
| LDO | 压差 1.7V > dropout 0.2V | 满足稳压 |
