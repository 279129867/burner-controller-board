# LTspice 仿真工程说明（4-20mA 链路 + 电源输入级）

> 本作品集当前用本机 Python 完成电路级直流/时域仿真（见 `电路级仿真.py`，结果已 PASS）。
> 本文件给出对应的 LTspice 搭法，供后续安装 LTspice（ADI 官网免费）后复现与出波形截图。

## 一、模块 A：4-20mA I/V 采集链路

### 电路拓扑
```
I1(电流源 4~20mA) ── R1=250Ω ── 节点 V_s ── Rf=1kΩ ── 节点 V_adc ── 运放跟随 ── 分压 R_DIV1/R_DIV2 ── ADC
                                          │
                                         Cf=100nF
                                          │
                                         GND
```

### 器件参数
| 位号 | 器件 | 值 | 说明 |
|---|---|---|---|
| I1 | 电流源 | 4/12/20mA 直流 | 模拟变送器 |
| R1 | 采样电阻 | 250Ω 1% | 得 1~5V |
| Rf | 滤波电阻 | 1kΩ | 与 Cf 组成低通 |
| Cf | 滤波电容 | 100nF | fc≈1.59kHz |
| U1 | 运放 | 轨到轨（如 LT1006/LM358 模型） | 缓冲跟随 |
| R_DIV1/R_DIV2 | 分压 | 10k/16.5k | 5V→3.11V，匹配 3.3V ADC |

### 仿真设置
- 直流工作点（.op）：分别扫 I1 = 4/12/20mA，读 V_s、V_adc。
- 瞬态（.tran 0 10ms）：I1 从 0 阶跃到 20mA，看 V_adc 建立时间。
- 预期结果：4mA→1.00V，12mA→3.00V，20mA→5.00V；ADC 入 ≤3.3V；99% 建立 ≈460µs（τ=100µs）。

## 二、模块 B：24V 电源输入级

### 电路拓扑
```
VIN(18~36V) ── F1(自恢复保险 2A) ── D_REV(MOS防反接) ── TVS(SMBJ24A) ── π滤波(L+C) ── 后级 DC-DC 5V ── LDO 3.3V
```

### 器件参数
| 位号 | 器件 | 值/型号 | 说明 |
|---|---|---|---|
| F1 | 自恢复保险 | 2A | 过流保护 |
| D_REV | 防反接 MOS | 理想开关模型 | 反接截止 |
| TVS | 钳位 | SMBJ24A | 钳位参考 ~26V |
| L_IN | 共模/功率电感 | 按 DC-DC 选型 | π 滤波 |
| U5V | DC-DC | 24→5V | 主电源 |
| U33 | LDO | 5→3.3V | 压差 1.7V > dropout 0.2V |

### 仿真设置
- 直流工作点：VIN = 18/24/30/36/-24V；验证反接阻断、过压钳位、LDO 压差。
- 预期结果：反接时后级 0V；30V 以上 TVS 钳位；LDO 满足稳压压差。
