# 模块 06：电源与隔离

> 所属：低氮燃烧控制器主控板 · 原理图模块 06

## 1. 功能概述
把 24V 宽压输入变换为数字、模拟、现场/通讯隔离所需电源，完成反接、过流、过压钳位与滤波，并实现各电源域与地的分区。

## 2. 电源树总览

```
24VDC(18~36V) ──► F1 保险 ──► D_REV 防反接 ──► TVS(SMBJ24A) ──► π滤波(L+C)
        │
        ├─► DC-DC 24V→5V ──► LDO 5V→3.3V(数字)
        │                    └─► LDO/磁珠 → 3.3V(模拟 VDDA)
        │
        └─► 隔离 DC-DC → 现场侧/通讯侧隔离电源（隔离地）
```

## 3. 分单元电路

### 3.1 输入保护级
| 器件 | 选型/参数 | 说明 |
|---|---|---|
| F1 | 自恢复保险/熔丝，2A | 过流保护 |
| D_REV | MOS 防反接（或二极管） | 反接截止，降低压降优选 MOS |
| TVS | SMBJ24A | 24V 钳位参考，过压泄放 |
| L_IN/C_IN | π 型滤波 + 共模电感 | 抑制浪涌与共模噪声 |

### 3.2 主控电源
| 器件 | 参数 | 说明 |
|---|---|---|
| U5V | DC-DC 24V→5V | 开关稳压，效率优先 |
| U33 | LDO 5V→3.3V | 数字/模拟分路，磁珠隔离 VDDA |
| 去耦 | 10µF + 100nF | 各 IC 电源脚 |

### 3.3 隔离电源
| 器件 | 说明 |
|---|---|
| U_ISO | 隔离 DC-DC，供光耦副边、RS485/CAN 隔离侧 |
| 隔离地 | 现场/通讯地与控制地分离，单点不直连 |

## 4. 仿真结果（Python 电路仿真）
| 输入 | 后级电压 | 状态 |
|---|---|---|
| 18V | 18.00V | OK |
| 24V | 24.00V | OK |
| 30V | 28.00V（TVS 钳位） | OK |
| 36V | 28.00V（TVS 钳位） | OK |
| -24V | 0.00V | 反接阻断 |
| LDO | 压差 1.7V > dropout 0.2V | 满足稳压 |

## 5. 设计要点
- 输入保护顺序：保险 → 防反接 → TVS → π 滤波，靠近电源入口。
- DC-DC 开关回路（输入电容、开关管、续流管、电感）围成小面积，减小辐射。
- 模拟 3.3V 经磁珠与数字分开，VDDA 去耦独立。
- 隔离 DC-DC 原副边不跨走信号线，隔离带下保持间距。
- 各地分区铺铜，单点汇接；功率地不借模拟地回流。
