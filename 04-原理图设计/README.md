# 04 原理图设计 —— 模块索引

低氮燃烧控制器主控板分模块电路说明。阶段：纸面 + 仿真，器件为选型建议，未采购、未画板。

| 模块 | 文件 | 核心内容 |
|---|---|---|
| 01 MCU 最小系统 | [01-MCU最小系统.md](01-MCU最小系统.md) | 主控、时钟、复位、下载、去耦、外设分配 |
| 02 模拟采集链路 | [02-模拟采集链路.md](02-模拟采集链路.md) | 温度、4-20mA、O₂/CO 信号链与量程匹配 |
| 03 隔离数字输入 | [03-隔离数字输入.md](03-隔离数字输入.md) | 火焰、干接点、脉冲隔离与整形 |
| 04 隔离驱动输出 | [04-隔离驱动输出.md](04-隔离驱动输出.md) | 阀门/风门/报警驱动、续流吸收、联锁安全态 |
| 05 通讯接口 | [05-通讯接口.md](05-通讯接口.md) | RS485(Modbus-RTU)、CAN 隔离与防护 |
| 06 电源与隔离 | [06-电源与隔离.md](06-电源与隔离.md) | 输入保护、DC-DC/LDO、隔离电源、接地分区 |

## 模块间连接关系
- 01 最小系统的 GPIO/ADC/定时器/通讯口，分别对接 02 采集、03 输入、04 驱动、05 通讯。
- 06 电源为全部模块供电；现场侧与通讯侧由隔离电源单独供电。
- 详细引脚对应见上级目录《IO分配表.md》。

## 统一口径
- 所有 EMC、安规、防爆、耐压指标为设计对标与预留，未实测，不宣称通过认证。
- 仿真验证结果见《../燃控仿真验证.py》《../06-仿真记录/电路级仿真.py》与《../测试与验证记录.md》。
