# 模块 04：隔离驱动输出

> 所属：低氮燃烧控制器主控板 · 原理图模块 04
> 包含：阀门/风门驱动、报警输出、联锁安全态。

## 1. 功能概述
MCU 经光耦隔离驱动继电器/固态开关，控制燃阀、风门与报警；对线圈尖峰、触点拉弧做抑制，并保证故障时输出回到安全态。

## 2. 信号链总览

```
MCU GPIO ──► 输出光耦 ──► 继电器/MOS/固态 ──► 现场负载(阀门/风门/报警)
                │            └ 续流二极管 / RC吸收
             隔离 DC-DC 供电
```

## 3. 分通道电路

### 3.1 阀门/风门输出
| 器件 | 选型/参数 | 说明 |
|---|---|---|
| 输出光耦 | 通用光耦 | 隔离 GPIO |
| 开关器件 | 继电器 / MOS / 固态继电器 | 按负载电流与类型选 |
| 续流二极管 | 1N4148/续流管，反并线圈两端 | 抑制断电尖峰 |
| 触点吸收 | RC 阻容（必要时压敏） | 抑制触点拉弧 |
| 负载端子 | 常开/常闭预留 | 按阀门类型接 |

- 通道：主燃阀、副阀/点火阀、风门执行器、备用 DO。

### 3.2 报警输出
| 器件 | 说明 |
|---|---|
| 光耦隔离 + 蜂鸣器/指示灯/外接端子 | 故障报警，预留常开/常闭 |

### 3.3 联锁安全态
- 运行中熄火、风压不足 → 状态机切断主燃阀/副阀并报警。
- MCU 复位、看门狗溢出、上电期间，输出默认关断（安全态）。
- 硬件预留紧急停回路端子；真实产品安全回路按安规实物联调。

## 4. 设计要点
- 继电器线圈紧贴续流二极管，引线短，减小尖峰环路。
- 触点侧 RC 吸收靠近触点；感性负载必做尖峰抑制。
- 驱动级与 MCU 间用光耦隔离，现场侧不共控制地。
- 功率输出板边布置，与模拟采集分开。
- 三极管/MOS 驱动基极/栅极限流，续流路径清晰。
