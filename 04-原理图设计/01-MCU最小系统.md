# 模块 01：MCU 最小系统

> 所属：低氮燃烧控制器主控板 · 原理图模块 01
> 阶段：纸面 + 仿真；器件为选型建议，未采购、未画板。

## 1. 功能概述
为主控 MCU 提供稳定供电、时钟、复位、下载调试与基本启动配置，是整板的控制核心。

## 2. 电路组成

| 子电路 | 器件/方案 | 参数 | 说明 |
|---|---|---|---|
| 主控 | STM32G0B1/G431（或 GD32F303 同级） | LQFP64/48 | M0+/M4F，多路 ADC、CAN、多路 UART、定时器 |
| 时钟 | 8MHz 无源晶振 + 2×20pF 负载电容 | ±20ppm | 也可用内部 HSI 省掉外部晶振 |
| 复位 | NRST 上拉 10k + RC + 复位按键 | RC 时间常数按数据手册 | 低电平复位 |
| 启动配置 | BOOT0 下拉 10k | 默认主Flash启动 | 预留启动模式选择 |
| 下载调试 | SWD 排针 4P | SWDIO/SWCLK/GND/3V3 | 下载与单步调试 |
| 去耦 | 每 VDD 100nF；VDDA 10µF+100nF + 磁珠 | 0402 | 靠近电源脚 |
| 指示 | 电源/运行/故障 LED，各串 1k | — | 巡检与调试 |

## 3. 信号链与连接

```
3V3 ──磁珠── VDDA(10µF+100nF)
VDD 各脚 ──100nF── GND
NRST ──上拉10k──3V3；RC + 按键到 GND
OSC_IN/OSC_OUT ── 8MHz 晶振 + 负载电容
SWDIO/SWCLK ── 调试排针
BOOT0 ──下拉10k── GND
GPIO ── 各功能模块（见 IO 分配表）
```

## 4. 设计要点
- VDDA 经磁珠与数字 3.3V 分离，减少数字开关噪声进入 ADC 参考。
- 去耦电容紧贴对应电源脚，先电容后过孔到地。
- 晶振靠近 MCU，走线短，下方铺地。
- 复位线、下载线远离功率与高频干扰。
- 预留看门狗（内部 IWDG）用于跑飞复位，故障时输出回到安全态。

## 5. 资源与外设分配（摘要）
- ADC：温度、4-20mA、O₂/CO、板温。
- 定时器输入捕获：火焰脉冲、转速/流量脉冲。
- UART：RS485；CAN：机组总线；备用串口扩展。
- GPIO：隔离输入、隔离驱动输出、指示灯。
