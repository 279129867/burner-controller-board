# 模块 03：隔离数字输入

> 所属：低氮燃烧控制器主控板 · 原理图模块 03
> 包含：火焰检测、干接点、脉冲输入。

## 1. 功能概述
把现场侧的开关量、脉冲量经隔离器件送入 MCU，实现现场与控制侧电气隔离，并完成限流、保护、整形与消抖。

## 2. 信号链总览

```
现场开关/脉冲 ──► 限流电阻 ──► TVS/保护 ──► 光耦 ──► 上拉/整形 ──► MCU(GPIO/EXTI/输入捕获)
```

## 3. 分通道电路

### 3.1 火焰检测输入
| 器件 | 选型/参数 | 说明 |
|---|---|---|
| 高速光耦 | 6N137 类 | 带宽高，避免丢脉冲 |
| 输入限流 | 电阻按现场电压/光耦 LED 电流计算 | 留 CTR 余量 |
| 后级 | 上拉电阻 → 定时器输入捕获/EXTI | 测脉冲频率/电平 |

- 要点：火焰信号多为脉冲/频率量，普通光耦带宽不足会漏脉冲，故走高速光耦 + 输入捕获。

### 3.2 干接点输入
| 器件 | 选型/参数 | 说明 |
|---|---|---|
| 通用光耦 | PC817 类 | 开关量隔离 |
| 上拉 | 副边 10k 上拉 | 确定电平 |
| 消抖 | RC + 软件滤波 | 机械触点防抖 |

- 通道：风压、液位/水位、限位/行程及备用 DI。

### 3.3 脉冲输入
| 器件 | 参数 | 说明 |
|---|---|---|
| 施密特门 | 整形 | 把不规则脉冲整形成方波 |
| 定时器 | 输入捕获 | 测周期/频率 |

## 4. 设计要点
- 隔离器件跨在现场侧与控制侧之间，隔离带下不走信号线。
- 输入先限流、保护，再进光耦；TVS 靠近端子。
- 光耦副边电平上拉，避免悬空误触发。
- 脉冲通道必须落在带输入捕获的定时器，不能用普通 GPIO 轮询读频率。
- 现场侧供电由隔离 DC-DC 提供，与控制地分离。
