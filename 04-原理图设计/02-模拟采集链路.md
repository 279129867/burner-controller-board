# 模块 02：模拟采集链路

> 所属：低氮燃烧控制器主控板 · 原理图模块 02
> 包含：温度采集、4-20mA 采集、O₂/CO 探头接口。

## 1. 功能概述
将现场温度、标准电流信号、烟气探头信号调理到 ADC 可接收的 0~3.3V 范围，完成采样前的阻抗匹配、滤波与量程匹配。

## 2. 信号链总览

```
热电偶 K型 ──► 仪表放大 ──► 冷端补偿 ──► RC低通 ──► ADC
PT100(预留) ─► 恒流源/电桥 ─► 仪表放大 ─► RC低通 ──► ADC
4-20mA ──► 250Ω(I/V) ──► RC低通 ──► 跟随 ──► 分压 ──► ADC
O₂/CO探头 ─► 仪表放大 ──► 二阶低通 ──► ADC
```

## 3. 分通道电路

### 3.1 温度采集（热电偶）
| 器件 | 选型/参数 | 说明 |
|---|---|---|
| 热电偶 | K 型 | 毫伏级输出 |
| 仪表放大器 | AD620 类/国产替代 | 增益按量程计算，高共模抑制 |
| 冷端补偿 | 板上温度传感器 | 补偿冷端温度 |
| 滤波 | RC 低通 | 靠近 ADC |
| 保护 | 限流 + TVS | 端子侧 |

- 换算：毫伏→温度（样机阶段查 K 型分度表；作品集用线性近似演示链路）。
- PT100 预留恒流源 + 电桥接口。

### 3.2 4-20mA 采集
| 器件 | 参数 | 说明 |
|---|---|---|
| 采样电阻 R_S | 250Ω，1%，1/4W | 4-20mA → 1~5V |
| 滤波 R_F/C_F | 1kΩ / 100nF | fc≈1.59kHz 低通 |
| 跟随运放 | 轨到轨 | 高阻抗缓冲 |
| 分压 R_DIV1/2 | 10k / 16.5k | 5V→3.11V，匹配 3.3V ADC |

- 仿真结果：4/12/20mA → 1.00/3.00/5.00V；ADC 入 0.62/1.87/3.11V；99% 建立 ≈460µs。
- 断线判断：电流 <3.6mA 判断线/故障；软件做零点、增益校准。

### 3.3 O₂/CO 探头
| 器件 | 参数 | 说明 |
|---|---|---|
| 仪表放大 | 低偏置 | 毫伏/毫安级放大 |
| 二阶低通 | 有源/无源 | 抑制带外噪声 |
| 标定 | 软件零点/增益 | 预留标定电位 |

## 4. 设计要点
- 模拟走线短，远离继电器、DC-DC 开关节点与晶振。
- 模拟地在 ADC 处星型汇接，采集回路面积小。
- 每通道独立 I/V，避免共地串扰。
- ADC 输入不得超 3.3V；分压留余量。
- 滤波电容选 C0G/稳定介质，避免容值漂移影响截止频率。
