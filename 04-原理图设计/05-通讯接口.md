# 模块 05：通讯接口（RS485 / CAN）

> 所属：低氮燃烧控制器主控板 · 原理图模块 05

## 1. 功能概述
提供对上通讯（RS485，Modbus-RTU）与炉区/机组总线（CAN 2.0B），两侧均做电气隔离与浪涌/ESD 防护。

## 2. 信号链总览

```
RS485:  MCU UART(TX/RX, DE/RE) ──► 隔离收发器 ──► 共模电感/TVS ──► A/B/GND 端子
CAN:    MCU bxCAN(RX/TX) ──► 隔离收发器 ──► 共模电感/TVS ──► CANH/CANL/GND 端子
```

## 3. RS485 电路
| 器件 | 选型/参数 | 说明 |
|---|---|---|
| 隔离收发器 | ADM2587 类集成隔离，或普通收发器 + 隔离 DC-DC | 半双工 |
| 方向控制 | DE/RE 由 MCU 同一/相邻引脚控制 | 半双工切换时序 |
| 防护 | A/B 间 TVS、共模电感 | 靠近端子 |
| 终端电阻 | 120Ω，可选贴 | 总线末端 |
| 协议 | Modbus-RTU | 作品集附帧格式与 CRC16 |

## 4. CAN 电路
| 器件 | 选型/参数 | 说明 |
|---|---|---|
| 隔离收发器 | ISO1042 类 | CAN 2.0B |
| 防护 | CANH/CANL TVS、共模电感 | 靠近端子 |
| 终端电阻 | 120Ω | 总线末端 |
| 波特率 | 250k/500k 预留 | 按总线长度定 |

## 5. 设计要点
- 隔离切断现场地电位差形成的地环路；隔离侧由隔离 DC-DC 供电。
- TVS、共模电感靠近接口端子，顺序：端子→防护→收发器。
- 终端电阻只放在总线末端，板上预留焊位。
- 485 方向切换留足收发建立/转向时间，避免帧首尾丢失。
- 通讯走线远离功率线圈与 DC-DC 开关节点。
